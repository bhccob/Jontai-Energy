# Round 54 Build Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build round 54 in the real Next.js site:
- the minimal glass header
- a still, light first view with four facts
- calmer Rewards with motion
- the sentence for Our solution
- the dark range wheel
- a simple footer
- a new `/products` page

**Architecture:** Put the logic that can be tested in `lib/` (`wheel.ts`, `catalog.ts`, `firstView.ts`, `homeCopy.ts`) with Node tests, as the site already does.
- The sections stay as server components.
- Each section's motion lives in its own small client component, like `HeroSkyMotion` and `CollectionMotion` do today. They use GSAP ScrollTrigger with Lenis and sticky CSS for held screens.
- Existing machinery is reused:
  - `[data-words]` rise and the `Words` split (`components/ui/Split.tsx`), which already translate.
  - `scrollTargets` for in-page anchors.
  - `OpenStatus`, `openState` and `lib/countup.ts`.
  - `OpenCategoryButton` for the delivery panel.
  - `HeroSkyMotion` for Rewards sliding over the first view.

**Tech Stack:** Next.js 14 app router, React 18, GSAP 3.13 + ScrollTrigger + `@gsap/react`, Lenis 1.3, Phosphor icons, plain CSS in `app/styles/`, `node --test` for `lib/`.

**Spec:** `docs/superpowers/specs/2026-11-14-round-54-showroom-design.md`. The visual reference for every section is `public/mockups/r54/site11.html?look=c&over=over` (CSS: `mock.css`, `mock6.css`, `mock7.css`, `mock9.css`, `mock11.css`). The `/products` reference is `products.html` ("Light pools"). Run the dev server and open them side by side.

## Global Constraints

- Branch `redesign/v9-after-hours`, worktree `.claude/worktrees/v9`. Commit per task. Never commit `.impeccable/review/` or `public/mockups/`. Push only when Bob says "Push it".
- One family: Archivo, using its width axis. Mixed light (300, stretch 112%) and bold (760–780, stretch 100%) in headings. No em dashes in copy.
- Colours: the site's tokens. Deep green `#0e2219`, ink `#173d2c`, cream `#f4f6ef`, veil `#dae9cd`, paper `#f6f8f2`, mint `#a9dcb2`.
- Every new English string goes in `lib/i18n/es.json` and `lib/i18n/zh.json`: under `strings`, or under `patterns` with `{0}` holes.
- No boxes round reading text, no eyebrow chips, no status dots, no decorative shapes. Glass only on what floats.
- Product pictures are clean cut-outs. No large blurred `drop-shadow` on dark ground; only a small contact shadow ellipse under the product.
- Reduced motion (`prefers-reduced-motion: reduce`) turns off:
  - held screens: the wheel becomes six still rows and the sentence shows full
  - floating, bobbing and leaning
  - count-ups and rises
  - the grow-in clip
- Anchors that must keep working: `#solar #cooling #backup #light #security #upstairs #products #rewards #visit #delivery #solution`.
- `npm test`, `node --test lib/i18n/translate.test.ts`, `npm run lint`, `npm run typecheck` and `npx next build` all pass at the end of every task that touches code.

## Review Focus

2. **A range anchor followed from another page.** For example `/products/bulbs` → footer or menu "LED lighting" → `/#light` should land with the wheel resting on LED lighting, not mid-turn. Tested in Task 1 (`restProgress`). Checked in Task 9.
3. **Short or narrow screens** (1366×640, 390×667). The first view, its facts and the sentence with its points still fit one screen with nothing clipped. Checked in Task 9 at those sizes.
4. **`/products?range=` with a bad, empty or repeated value** should show All, not an empty page. Tested in Task 1 (`filterFromParam`).
5. **Opening a product from `/products`** should open the sheet over the page, and Back should return to the same filter and scroll position. Checked in Task 7.
